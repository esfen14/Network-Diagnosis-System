# PinPoint — Diagnostic System


## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Recharts (integrated network performance chart) 
- Lucide React (icons)

## To start

1. Create new terminal
2. Install all necessary dependencies: npm install
3. Run the code: npm run dev

Open local host — you should land on the LOGIN page. Submit the form to navigate to the dashboard.
